# Hearth & Herald - Bug Reports & Issues

Public tracker for **[Hearth & Herald](https://www.nexusmods.com/mountandblade2bannerlord/mods/11742)**,
a Mount & Blade II: Bannerlord mod by DevoidAxis.

This repo holds no code. It exists so anyone can file a bug or request a
feature with a proper form, screenshots, and follow-up, which the Nexus posts
tab is not great at.

## Filing a good bug report

Open a [new issue](../../issues/new/choose) and include:

- Game version (e.g. 1.3.15) and mod version (Mod Options page shows it)
- What happened, what you expected, and the steps to reproduce
- Your load order if the problem smells like a mod conflict
- A crash report or the `Configs/ModLogs/DevoidAxis.HearthHerald.log` file if you have one
